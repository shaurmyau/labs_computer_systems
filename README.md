В репозитории сохранены исходные методические материалы и подготовлены четыре самостоятельных проекта по семинарам 3, 5, 6–7 и 8–9.

| Каталог | Работа | Результаты |

| [lab-03-zabbix](lab-03-zabbix/README.md) | Семинар 3 — установка и настройка Zabbix 7.4 | Сценарий установки Ubuntu 22.04, регистрация узла и триггера, проверка сервисов |
| [lab-05-sli-slo-sla](lab-05-sli-slo-sla/README.md) | Семинар 5 — SLI, SLO и SLA | Описание OrderFlow, три SLI, цели SLO, проект SLA и правила Prometheus |

| [lab-08-09-quality-economics](lab-08-09-quality-economics/README.md) | Семинары 8–9 — экономика качества | PAF-классификация, стоимость простоя, меры защиты, бюджет ошибок и остаточный риск |

## Принятые допущения

Работы 5, 6–7 и 8–9 используют общий учебный пример — сервис обработки онлайн-заказов OrderFlow. Финансовые, нагрузочные и тестовые значения в этих проектах являются явно обозначенными учебными исходными данными, выбранными для выполнения расчётов; они не выдаются за телеметрию реально работающего коммерческого сервиса.

Лабораторная 3 содержит исполняемые инструкции по установке Zabbix. Установка на реальном сервере требует Ubuntu 22.04, прав root и сетевого доступа к репозиториям пакетов. Установка на сервере пользователя из этого репозитория не производилась.

Файлы исходных заданий «Семинар 3(1).docx», «Семинар 5.docx», «Семинар 6, 7.docx» и «Семинар 8,9.docx» сохранены в корне без изменений.
