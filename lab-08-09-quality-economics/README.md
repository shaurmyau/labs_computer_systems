# Семинары 8–9. Экономика качества функционирования компьютерных систем

## Выбранная система

OrderFlow — учебный сервис обработки онлайн-заказов. Сценарии и определения согласованы с работами семинаров 5 и 6–7.

## Состав результатов

- docs/paf-costs.md — не менее 12 статей по четырём группам модели PAF, включая скрытые затраты.
- docs/downtime-economics.md — расчёт прямых потерь выручки и стоимости обработки потерянных заказов.
- docs/protection-investments.md — ожидаемые потери до/после мер, ΔEL, чистый выигрыш и экономия за счёт сокращения MTTR.
- docs/error-budget-risk.md — бюджет ошибок, расход и остаток, политика исчерпания и документ принятия остаточного риска.
- src/economics.py — воспроизводимые функции расчётов.
- tests/test_economics.py — автоматические проверки ключевых значений и граничных условий.

## Запуск

~~~bash
python3 src/economics.py
python3 -m unittest discover -s tests -v
~~~

Требуется только Python 3.

## Допущения

Все суммы в рублях, оценки вероятности, длительность простоев и стоимость мер — учебные исходные данные, самостоятельно выбранные для демонстрации формул задания. Это не бухгалтерская отчётность и не фактическая статистика реального OrderFlow. При практическом применении исходные величины нужно заменить данными финансовой службы, мониторинга и постмортемов инцидентов.
