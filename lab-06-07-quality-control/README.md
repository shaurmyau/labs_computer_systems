# Семинары 6–7. Документирование результатов контроля качества

## Выбранная система

**Sirius EDA** — учебная система заказа питания в столовой. Рассматриваются FastAPI API, PostgreSQL, RabbitMQ, обработчики кухни и доставки и Saga-компенсация. Для отчёта используется модельная версия 1.0.0-rc1.

## Результат работы

Все материалы объединены в один документ: [единый отчёт по семинарам 6–7](docs/report.md).

Внутри отчёта сохранены шесть частей:
1. отчёт о тестировании;
2. протокол модельной проверки;
3. карточка дефекта BUG-001;
4. протокол учебной инспекции;
5. показатели качества с формулами и расчётами;
6. корректирующие и предупреждающие рекомендации.

## Границы достоверности

Документ представляет учебную модель контроля качества Sirius EDA. Количественные показатели и сценарий дефекта специально обозначены как модельные исходные данные, а не как фактический прогон текущей версии проекта. Перед использованием в реальном релизном решении нужно заменить их данными CI, журналами API/RabbitMQ, состояниями PostgreSQL и результатами повторной проверки.

В этой работе не создаётся отдельная программа расчёта метрик: лекция требует документировать результаты проверок и показатели качества, а не разрабатывать программный продукт.
