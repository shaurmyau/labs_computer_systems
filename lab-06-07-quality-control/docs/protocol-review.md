## 1. Методика

Инспекция проводится как анализ проектных решений и связанных с ними требований. Проверяются:
- согласованность фиксации заказа в PostgreSQL и публикации события RabbitMQ;
- обработка повторно доставленных сообщений;
- передача correlation_id между API и фоновыми компонентами;
- корректность компенсационных действий Saga;
- наличие наблюдаемости для диагностики незавершённых заказов.

Это документальный учебный пример. Он не содержит утверждений о проверке конкретных строк кода или фактическом code review pull request.

## 2. Замечания

| ID | Замечание | Риск | Рекомендация | Приоритет |
|---|---|---|---|---|
| REV-001 | Необходимо гарантировать сохранение бизнес-события при отказе RabbitMQ после фиксации состояния заказа | Заказ может остаться в промежуточном состоянии | Рассмотреть transactional outbox и повторную публикацию | Высокий |
| REV-002 | Повторная доставка сообщения должна быть безопасной для каждого consumer | Повторное списание или повторный побочный эффект | Проверять идемпотентность по event_id/order_id | Высокий |
| REV-003 | Требуется единая корреляция HTTP-запроса, сообщения и действий worker | Усложняется расследование распределённого сбоя | Передавать correlation_id в заголовках сообщения и писать его в структурированные логи | Средний |
| REV-004 | Для сообщений, которые не удаётся обработать после повторов, нужен контролируемый маршрут | Необрабатываемое сообщение может блокировать очередь | Использовать DLQ и регламент повторной обработки | Средний |

## 3. Решение по инспекции

Замечания REV-001 и REV-002 следует устранить или принять владельцем системы с документированным обоснованием до релиза. REV-003 и REV-004 включить в план улучшений и проверить при интеграционном тестировании.

## 4. Контроль устранения

Каждое замечание должно быть связано с тикетом и pull request. После исправления инспектор проверяет изменение, а QA прикладывает результаты повторных тестов. Статус замечания меняется на закрытый только после подтверждения результата, а не после самого факта изменения документа или кода.
